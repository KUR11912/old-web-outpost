# 旧网驿站

《网络梗考古》的独立第一人称自由探索原型。Vite + TypeScript + Three.js，目前包含 84×74 米地图和回声档案馆完整调查流程；原 28×28 米驿站区域位于西南侧。保持基础 Y2K 低多边形效果，未改动原字符网页游戏或 Blender 工程。

## 直接运行

当前电脑双击 `启动旧网驿站.cmd`，会检查已有服务，必要时在后台启动并打开 **http://127.0.0.1:5180/**。关闭浏览器不会关闭后台服务；重启电脑后再次双击即可。

也可在本目录执行：

```powershell
npm install
npm run dev
```

需要 Node.js 22.12+（也支持 20.19+）。本机已有依赖，启动脚本优先使用 PATH 中的 Node，再尝试已安装的 Codex 附带 Node。脚本不下载软件。若把项目复制到其他电脑，应先正常安装 Node.js，并执行 `npm install`。

构建：`npm run build`；预览构建结果：`npm run preview`（同用 5180 端口，先关闭开发服务）。不能直接双击 `index.html`，GLB 和模块需要通过 HTTP 服务加载。本地址仅本机可访问，未部署到公网。

## 操作与完整流程

1. 点击“点击开始探索”，进入鼠标锁定；若浏览器限制锁定，自动改用拖拽。也可直接点击“拖拽模式进入”。
2. WASD 行走，鼠标转头；拖拽模式按住左键转头。Esc 暂停并释放鼠标。
3. 沿石板路到门前的红色邮箱。靠近并看向邮箱，出现 E 提示后按 E。
4. 阅读虚构留言，点击“收下线索卡”。得到“蓝瘦香菇图片”；它已有底部文字，调查目标是找回含义和使用语境。图片 ID 沿用 `missing-caption-image`，已领取的旧存档不用重领。
5. 按 B 随时打开背包。重复调查只回看留言，不重复领取。只读信未领取时，刷新不会自动授予卡片。
6. 刷新恢复位置、视角、调查状态与线索。关闭窗口后须再次点击场景/进入按钮才能移动。
7. 按 M 或点击“全图”查看同一 3D 场景的俯视全图。全图暂停行走，返回后明确点击继续；沿石板路向北到回声档案馆。
8. 靠近门前的旧终端、聊天记录查看器和图片缓存终端，分别看向物件、按 E 阅读并领取线索。背包可以查看每张卡的完整内容和可展开资料说明。
9. 调查门前“整理线索”桌，收齐四卡后完成含义关联与语境判断。选错会解释原因并提供回看卡片按钮；可以修改、重试，答案草稿自动保存。
10. 两题判断正确并提交后显示“档案馆调查完成”，下一目标为前往断链桥。本轮桥保持开放，未接入正式解锁条件。

“重置测试进度”需要在游戏确认框再确认，只清空此原型自己的存档并回到入口。窗口打开、Esc、切换窗口/标签页时均停止移动。没有跳跃、奔跑或战斗。

## 结构与存档

- `src/world.ts`：场景、真实 GLB 加载、摆放、材质和碰撞数据。
- `src/map-config.ts`：全图尺寸、地点、道路、河桥、区域、后续任务接入点。
- `src/map-environment.ts`：两岸地形、桥梁、档案馆与灯塔模型摆放、外围边界和新增植被/道路实例。
- `src/archive-scene.ts`：档案馆三个调查物件与整理桌，集中坐标、名称、碰撞、可瞄准点；低多边形几何与128像素屏幕纹理。
- `src/archive-data.ts`：四张线索、两个判断、答案反馈、资料说明、报道参考与配文比较配置。
- `src/investigation-ui.ts`：复用复古窗口的阅读、领取、背包详情、两步关联与调查完成流程。
- `src/player.ts`：第一人称操作、鼠标锁定/拖拽、平面胶囊碰撞、暂停恢复。
- `src/main.ts` / `style.css`：邮箱、线索卡、背包、复古窗口和提示。
- `src/save.ts`：`old-web-outpost:save:v1` 独立 localStorage，版本 1；位置、视角、调查、线索去重与数据校验。
- `public/assets/`：游戏资源；`dist/`：实际构建产物。
- `qa/`：浏览器验收脚本、实际运行截图和 JSON 报告。

每次收集、选择答案和暂停立即保存，行走约每 1.5 秒保存，离开页面再保存。沿用 v1 key 与版本；旧位置、视角、调查和已领取线索保持。新增 `archive: { answers: { meaning: null, context: null }, completed: false }`，旧存档自动补默认值。合法错误答案也保存，刷新后可修改；只有四卡齐全、两题正确且玩家明确提交，才能记录完成。无新增奖励，重复调查只回看资料。损坏或不同版本存档恢复初始状态；浏览器拒绝存储时底栏显示提示，不把保存失败说成成功。存档按浏览器与地址隔离。
